# syntecxhub_statistical-plots
Statistical analysis and visualization of dataset using Pandas, Matplotlib, and Seaborn.
# Statistical Plots & Distribution Analysis

This project focuses on analyzing and visualizing data distributions using Python.  
It uses statistical plots to understand patterns, skewness, and trends in the dataset.

## Tools & Libraries
- Python  
- Pandas  
- Matplotlib  
- Seaborn  

## Project Features
- Data loading and cleaning  
- Histogram of Age Distribution  
- KDE (Density) plots  
- Skewness analysis of Age and Fare  
- Visual interpretation of data  

## Files Included
- `.ipynb` notebook file  
- Dataset (`.csv`)  
- Saved plot images 

## Purpose
The main objective of this project is to understand how data is distributed and to analyze skewness using statistical visualization techniques.

## How to Run
1. Open the notebook in Jupyter or VS Code  
2. Run all cells  
3. View the plots and results
